## 🎯 Learning Goal

The goal of this repository is to understand probability concepts that form the mathematical foundation of:

**Probability → Statistics → Machine Learning → Deep Learning → Generative AI**

The focus is on understanding concepts through **numerical problems, practical examples, and Python implementations** rather than memorizing formulas alone.
