# 📐 Linear Algebra

A structured learning repository covering the **Linear Algebra concepts required for Machine Learning and Data Science**.

This repository contains my notes, formulas, numerical problems, examples, Python implementations, and learning resources to build a strong mathematical foundation for ML.

## 📚 Topics Covered

* Scalars, Vectors & Matrices
* Matrix Representation
* Types of Matrices
* Matrix Operations
* Matrix Addition & Subtraction
* Scalar Multiplication
* Matrix Multiplication
* Transpose of a Matrix
* Determinant
* Inverse of a Matrix
* Rank of a Matrix
* Systems of Linear Equations
* Gaussian Elimination
* Eigenvalues & Eigenvectors
* Vector Spaces
* Linear Independence & Dependence
* Basis & Dimension
* Dot Product
* Vector Norms
* Orthogonality
* Projections
* Principal Component Analysis (PCA)

## 🎯 Learning Goal

The goal of this repository is to understand the mathematical concepts of Linear Algebra that form an important foundation for:

**Linear Algebra → Machine Learning → Deep Learning → Generative AI**

The focus is on understanding concepts through **step-by-step numerical problems, practical examples, and Python implementations**.
